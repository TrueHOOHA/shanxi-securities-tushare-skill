## 个股异常波动

接口：stk_shock
描述：获取交易所每日发布的股票异常波动记录。可按股票代码、单个交易日或日期区间查询。
限量：建议按交易日循环提取；具体单次返回上限以服务端实际返回为准。

**输入参数**

名称 | 类型 | 必选 | 描述
---- | ---- | ---- | ----
ts_code | str | N | 股票代码，例如 `000001.SZ`
trade_date | str | N | 交易日期（YYYYMMDD）
start_date | str | N | 开始日期（YYYYMMDD）
end_date | str | N | 结束日期（YYYYMMDD）

`ts_code`、`trade_date`、`start_date/end_date` 至少提供一个；按日期区间查询时建议同时给出 `start_date` 和 `end_date`。

**输出参数**

名称 | 类型 | 默认显示 | 描述
---- | ---- | ---- | ----
ts_code | str | Y | 证券代码
trade_date | str | Y | 公告/交易日期（YYYYMMDD）
name | str | Y | 证券名称
trade_market | str | Y | 交易所名称，实测为“上交所 / 深交所 / 北交所”
reason | str | Y | 异常波动说明
period | str | Y | 异常期间，通常为 `YYYY-MM-DD-YYYY-MM-DD`

**接口示例**

```python
import sxsc_tushare as sx

pro = sx.get_api(env='prd')

# 某个交易日的全部异常波动
df = pro.stk_shock(trade_date='20261123')

# 某只股票在日期区间内的异常波动
df = pro.stk_shock(
    ts_code='002015.SZ',
    start_date='20250101',
    end_date='20261124'
)
```

**说明**

- `trade_market` 返回的是交易所名称，不是“主板/创业板/科创板”等板块名称。
- 常见 `reason` 包括连续三个交易日涨跌幅偏离值累计 20%、创业板/科创板 30%、北交所 ±40% 等；以接口返回文本为准。
- 不是每个交易日都有记录，空结果不代表接口失败。

**关联接口**

| 接口 | 说明 |
|---|---|
| `stk_high_shock` | 严重异常波动（10日/30日等更长周期） |
| `stk_alert` | 交易所重点提示证券 |
| `stock_basic` | 股票基础信息 |
