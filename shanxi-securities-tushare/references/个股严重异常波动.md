## 严重异常波动证券

接口：stk_high_shock
描述：获取交易所每日发布的严重异常波动证券记录。实测除股票外，也可能包含可转债等交易所公布的证券。
限量：建议按交易日或日期区间循环提取；具体单次返回上限以服务端实际返回为准。

**输入参数**

名称 | 类型 | 必选 | 描述
---- | ---- | ---- | ----
ts_code | str | N | 证券代码，例如 `000001.SZ`、`111012.SZ`
trade_date | str | N | 交易日期（YYYYMMDD）
start_date | str | N | 开始日期（YYYYMMDD）
end_date | str | N | 结束日期（YYYYMMDD）

`ts_code`、`trade_date`、`start_date/end_date` 至少提供一个；按日期区间查询时建议同时给出 `start_date` 和 `end_date`。

**输出参数**

名称 | 类型 | 默认显示 | 描述
---- | ---- | ---- | ----
ts_code | str | Y | 证券代码
trade_date | str | Y | 公告/交易日期（YYYYMMDD）
name | str | Y | 证券名称
trade_market | str | Y | 交易所名称，实测为“上交所 / 深交所 / 北交所”
reason | str | Y | 严重异常波动说明
period | str | Y | 异常期间；常见格式为 `YYYY-MM-DD-YYYY-MM-DD`，实测也有 `YYYYMMDDYYYYMMDD` 无分隔符格式

**接口示例**

```python
import sxsc_tushare as sx

pro = sx.get_api(env='prd')

df = pro.stk_high_shock(
    start_date='20250101',
    end_date='20261124'
)

# 也可按证券代码过滤
df = pro.stk_high_shock(
    ts_code='111012.SZ',
    start_date='20250101',
    end_date='20261124'
)
```

**数据示例（2025-01-01 至 2026-11-24 实测全量）**

```
    ts_code trade_date  name trade_market                    reason           period
0  688613.SH   20261118  奥精医疗          上交所  连续30个交易日内收盘价格跌幅偏离值累计达-70%  2026111820261202
1  111012.SZ   20261111  福新转债          上交所  连续30个交易日内收盘价格涨幅偏离值累计达200%  2026111120261125
```

**说明**

- `trade_market` 是交易所名称，不是板块名称。
- 该接口可能返回可转债等非股票证券，名称字段不一定是“个股”。
- `period` 的日期格式并不完全统一，解析时不要假定一定有分隔符。
- 数据量随市场情况变化；按日期分批拉取更稳妥。

**关联接口**
