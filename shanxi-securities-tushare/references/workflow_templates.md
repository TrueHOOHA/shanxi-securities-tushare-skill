# Workflow Templates 详细参考
> 模板是流程规范，不绑定具体命令行工具。


> 本文件是 SKILL.md 中 Workflow templates 的完整展开版。执行任何模板前，先查阅 `API接口对应表.md`。

---

## 1. 单标的行情分析

**适用：**
- 看下 XX 最近怎么样
- 这票最近强不强
- 今年以来表现如何

**默认流程：**
1. 解析标的（股票代码/名称 → `ts_code` 标准格式）
2. 确定时间范围（"最近"默认 20 交易日，"今年"从 1 月 1 日）
3. 取行情 + 必要基础指标
   - 查 `API接口对应表.md` → `daily` / `weekly` / `monthly`
   - 查 `API接口对应表.md` → `daily_basic`（估值指标）
4. 总结区间涨跌、成交活跃度、高低点、波动
5. 输出一句结论 + 关键数字

---

## 2. 多标的横向对比

**适用：**
- XX 和 YY 谁更强
- 把这几家公司对比一下

**默认流程：**
1. 锁定对象（统一转换为 `ts_code`）
2. 统一时间口径（所有标的相同起止日期）
3. 选 3～5 个关键指标（涨跌幅、PE、ROE、营收增速等）
4. 输出对比表
5. 给出"谁在哪方面更强"的总结

---

## 3. 财务质量快照

**适用：**
- 看下 XX 财报
- 最近几个季度利润趋势
- 财务质量怎么样

**默认流程：**
1. 拉最近 8 个季度 + 最近年度财务核心数据
   - 查 `API接口对应表.md` → `income`（营收/净利润）
   - 查 `API接口对应表.md` → `fina_indicator`（ROE/毛利率）
   - 查 `API接口对应表.md` → `balancesheet` / `cashflow`（资产负债/现金流）
2. 区分营收、利润、毛利率、ROE、现金流
3. 标出改善 / 恶化 / 波动点
4. 说明累计值、单季值、同比口径

---

## 4. 估值分析 / 筛选

**适用：**
- 现在估值高不高
- 谁更便宜
- 筛低估值高股息

**默认流程：**
1. 明确标的池（单个股票 / 行业板块 / 自定义列表）
2. 拉 `daily_basic` 等估值指标
   - 查 `API接口对应表.md` → `daily_basic`（PE/PB/股息率）
3. 必要时联动财务质量（`fina_indicator`）
4. 输出排序、极值、口径说明

---

## 5. 资金流追踪

**适用：**
- 最近资金在买什么
- 北向最近流向哪里
- 主力资金流入最多的是谁

**默认流程：**
1. 明确资金口径（北向 / 主力 / 龙虎榜 / 板块资金）
2. 确定时间窗（"最近"默认 5～20 交易日）
3. 拉净流入 / 活跃成交 / 持续性
   - 查 `API接口对应表.md` → `moneyflow`（个股资金流）
   - 查 `API接口对应表.md` → `moneyflow_hsgt`（沪深港通）
   - 查 `API接口对应表.md` → `top_list`（龙虎榜）
4. 和价格表现联动解释
5. 避免把单日噪声说成趋势

---

## 6. 板块 / 题材轮动分析

**适用：**
- 最近哪个板块最强
- 机器人最近强在哪
- 某概念板块里有哪些成分股

**默认流程：**
1. 确定分类口径（申万 / 中信 / 同花顺概念）
2. 拉板块区间表现
   - 查 `API接口对应表.md` → `index_daily`（指数行情）
   - 查 `API接口对应表.md` → `index_classify`（申万行业）
3. 必要时联动成分股、资金流、涨停梯队
4. 输出强势板块排行与代表标的

---

## 7. 公告 / 新闻 / 事件梳理

**适用：**
- 最近有什么公告
- 有没有什么催化
- 最近新闻面怎么样

**默认流程：**
1. 明确对象和时间窗
2. 先查 `API接口对应表.md` 确认公告/新闻/研报接口是否可用
3. 若对应表暂无映射：明确告知当前 skill 暂不支持该类接口直连，避免凭记忆调用
4. 若后续补齐映射：按对应文档取数、去噪并提炼 3～5 条主线
5. 区分事实、公告、媒体解读；必要时结合股价异动做弱因果解释

---

## 8. 数据导出与研究准备

**适用：**
- 拉一份 CSV
- 做回测数据表
- 导出某段时间的行情/财务数据

**默认流程：**
1. 明确数据范围、频率、字段
2. 采用分段策略取数（按年/季度切片）
3. 清洗、去重、统一字段类型
4. 输出 CSV / parquet
5. 给出文件路径和元信息（接口名、请求参数、拉取时间、数据行数）

---

## 9. 综合研究简报

**适用：**
- 给我快速研究一下 XX
- 做个投资者视角简报
- 先给个全景判断

**默认流程：**
1. 一句话结论
2. 行情表现（走势 + 关键数字）
3. 财务趋势（营收/利润/质量）
4. 估值水平（PE/PB/相对行业）
5. 资金流情况（主力/北向）
6. 公告 / 新闻催化
7. 风险点
8. 值得继续深挖的问题
