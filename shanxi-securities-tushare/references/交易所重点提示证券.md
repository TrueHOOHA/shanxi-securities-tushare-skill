## 交易所重点提示证券

接口：stk_alert
描述：获取交易所发布的重点提示证券，实测包含股票、ETF/LOF、可转债等证券。
限量：建议按日期循环提取；具体单次返回上限以服务端实际返回为准。

**输入参数**

名称 | 类型 | 必选 | 描述
---- | ---- | ---- | ----
ts_code | str | N | 证券代码，例如 `001896.SZ`
trade_date | str | N | 重点提示起始日期（YYYYMMDD）
start_date | str | N | 开始日期（YYYYMMDD）
end_date | str | N | 结束日期（YYYYMMDD）

`trade_date` 筛选的是提示的 `start_date`，不是公告日期；返回记录中的 `end_date` 是提示参考截至日期。

**输出参数**

名称 | 类型 | 默认显示 | 描述
---- | ---- | ---- | ----
ts_code | str | Y | 证券代码
start_date | str | Y | 重点提示起始日期
name | str | Y | 证券名称
end_date | str | Y | 重点提示参考截至日期
type | str | Y | 提示类型；实测为“交易所重点提示证券”

**接口示例**

```python
import sxsc_tushare as sx

pro = sx.get_api(env='prd')

# 某一天开始的重点提示
df = pro.stk_alert(trade_date='20261123')

# 按证券代码和日期区间查询
df = pro.stk_alert(
    ts_code='111012.SZ',
    start_date='20250101',
    end_date='20261124'
)
```

**说明**

- `start_date`、`end_date` 均以接口返回的日期字符串为准。
- 同一证券可能在多个起始日期被重复提示，按需去重。
- 重点提示是交易所关注信号，不等同于处罚或退市结论。
