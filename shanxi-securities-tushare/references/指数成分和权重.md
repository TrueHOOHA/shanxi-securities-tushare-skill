## 指数成分和权重
----

接口：index_weight
描述：获取各类指数成分和权重，**月度数据** ，建议输入参数里开始日期和结束日分别输入当月第一天和最后一天的日期。
来源：指数公司网站公开数据

> 注：本接口仅覆盖交易所/指数公司发布的指数（如 `000300.SH`、`399300.SZ`），不含申万指数；传 `801xxx.SI`、`85xxxx.SI` 一律返回 0 行。

**输入参数**

名称 | 类型  | 必选 | 描述
---- | ----- | ---- | ----
index_code | str | Y | 指数代码（二选一），来源<a href="https://tushare.pro/document/2?doc_id=94">指数基础信息接口</a>
trade_date | str | Y | 交易日期（二选一，格式YYYYMMDD，下同）
start_date | str | N | 开始日期
end_date | None | N | 结束日期

**输出参数**

名称 | 类型 | 描述
--- | ---- | ----
index_code | str | 指数代码
con_code | str | 成分代码
trade_date | str | 交易日期
weight | float | 权重

**接口调用**

```python

import sxsc_tushare as sx
pro = sx.get_api(env='prd')

#提取沪深300指数2018年9月成分和权重
df = pro.index_weight(index_code='399300.SZ', start_date='20180901', end_date='20180930')

```
