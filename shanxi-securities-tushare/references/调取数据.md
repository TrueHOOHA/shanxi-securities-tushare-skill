## 调取数据

本 skill 统一通过 `sxsc_tushare` Python 库调取数据（该库现已可通过 pip 直接安装）。

## 前提条件

1. 已经在山西证券开户并开通 PTrade 业务。
2. 已经获取到山西证券 Tushare 的 token 码。
3. 已安装 `sxsc_tushare` 库（未安装时直接 `pip install sxsc_tushare` 即可）。

---

## Python SDK

### 1. 安装库

```bash
pip install sxsc_tushare
```

### 2. 导入库

```python
import sxsc_tushare as sx
import os
```

### 3. 设置 Token

```python
token = os.getenv('SXSC_TUSHARE_TOKEN') 
sx.set_token(token)
```

> **注意**：以上方法只需要在第一次或者 token 失效后调用，完成调取 tushare 数据凭证的设置，正常情况下不需要重复设置。

### 4. 初始化 Pro 接口

```python
pro = sx.get_api(env='prd')  # 'prd'：python环境和PTrade仿真客户端，'qa' ：PTrade生产客户端
```

**环境参数说明：**

- **PTrade仿真客户端/纯 Python 环境**：`pro = sx.get_api(env="prd")`
- **PTrade生产客户端**：`pro = sx.get_api(env="qa")`

### 5. 数据调取

以获取交易日历信息为例：

**方式一：直接调用方法**

```python
df = pro.trade_cal(
    exchange='', 
    start_date='20180901', 
    end_date='20181001', 
    fields='exchange,cal_date,is_open,pretrade_date', 
    is_open='0'
)
```

**方式二：使用 query 通用方法**

```python
df = pro.query(
    'trade_cal', 
    exchange='', 
    start_date='20180901', 
    end_date='20181001', 
    fields='exchange,cal_date,is_open,pretrade_date', 
    is_open='0'
)
```
