## 调取数据

本 skill 统一通过 `sxsc_tushare` Python 库调取数据（该库现已可通过 pip 直接安装）。

## 前提条件

1. 已经在山西证券开户并开通 PTrade 业务。
2. 已经获取到山西证券 Tushare 的 token 码。
3. 已安装 `sxsc_tushare` 库（未安装时直接 `pip install sxsc_tushare` 即可）。

---

## Python SDK

### 1. 安装库

```bash
pip install sxsc_tushare
```

### 2. 导入库

```python
import sxsc_tushare as sx
```

### 3. 设置 Token（写入文件，不用环境变量）

Token 凭证保存在**用户主目录的一个 csv 文件**里（默认 `~/sxsc_tk.csv`，文件名以 `sxsc_tushare.upass.TOKEN_F_P` 为准，旧构建可能是 `jsdata_tk.csv`），内容为两行：

```
token
你的token值
```

首次使用或 token 失效时写入一次（此后无需重复设置）：

```python
sx.set_token('你的token')   # 写入 ~/sxsc_tk.csv
```

> **注意**：本 skill 全部脚本只读上述 token 文件。

### 4. 初始化 Pro 接口

```python
# token 自动从 token 文件读取；也可显式传入（推荐，避免 get_token() 失败时的 stdout 噪声）：
#   import os, pandas as pd, sxsc_tushare.upass as up
#   p = os.path.join(os.path.expanduser("~"), getattr(up, "TOKEN_F_P", "sxsc_tk.csv"))
#   token = pd.read_csv(p, dtype=str)["token"].iloc[0].strip()
#   pro = sx.get_api(token, env='prd')
pro = sx.get_api(env='prd')  # 'prd'：python环境和PTrade仿真客户端，'qa' ：PTrade生产客户端
```

**环境参数说明：**

- **PTrade仿真客户端/纯 Python 环境**：`pro = sx.get_api(env="prd")`
- **PTrade生产客户端**：`pro = sx.get_api(env="qa")`

### 5. 数据调取

以获取交易日历信息为例：

**方式一：直接调用方法**

```python
df = pro.trade_cal(
    exchange='', 
    start_date='20180901', 
    end_date='20181001', 
    fields='exchange,cal_date,is_open,pretrade_date', 
    is_open='0'
)
```

**方式二：使用 query 通用方法**

```python
df = pro.query(
    'trade_cal', 
    exchange='', 
    start_date='20180901', 
    end_date='20181001', 
    fields='exchange,cal_date,is_open,pretrade_date', 
    is_open='0'
)
```
