## 调取数据

本 skill 统一通过 `sxsc_tushare` Python 库调取数据（该库现已可通过 pip 直接安装）。

## 前提条件

1. 已经在山西证券开户并开通 PTrade 业务。
2. 已经获取到山西证券 Tushare 的 token 码。
3. 已安装 `sxsc_tushare` 库（未安装时直接 `pip install sxsc_tushare` 即可）。

---

## Python SDK

### 1. 安装库

```bash
pip install sxsc_tushare
```

### 2. 导入库

```python
import sxsc_tushare as sx
```

### 3. 设置 Token（写入文件，不用环境变量）

Token 凭证由 `sx.set_token()` 写入用户主目录的 csv 文件（当前构建为 `~/sxsc_tk.csv`），内容为两行：

```
token
你的token值
```

首次使用或 token 失效时写入一次（此后无需重复设置）：

```python
sx.set_token('你的token')
```

> **注意**：文件名由 SDK 内部常量决定，不要在自己代码里硬编码/解析它——直接调 `sx.get_api(env='prd')`，SDK 会自己去读。

### 4. 初始化 Pro 接口

```python
pro = sx.get_api(env='prd')  # 'prd'：python环境和PTrade仿真客户端，'qa' ：PTrade生产客户端
```

不传 token 时 SDK 自动从 `sx.set_token()` 写过的凭证文件读取。读不到 token 时它会在 stdout 打一行
`get token error.` 并抛 `Exception: api init error.`——这是唯一的异常分支，不要为这一行
噪声加 redirect；token 是否失效统一用 `scripts/check_env.py`（内含鉴权探针）判定。

**环境参数说明：**

- **PTrade仿真客户端/纯 Python 环境**：`pro = sx.get_api(env="prd")`
- **PTrade生产客户端**：`pro = sx.get_api(env="qa")`

### 5. 数据调取

以获取交易日历信息为例：

**方式一：直接调用方法**

```python
df = pro.trade_cal(
    exchange='',
    start_date='20180901',
    end_date='20181001',
    fields='exchange,cal_date,is_open,pretrade_date',
    is_open='0'
)
```

**方式二：使用 query 通用方法**

```python
df = pro.query(
    'trade_cal',
    exchange='',
    start_date='20180901',
    end_date='20181001',
    fields='exchange,cal_date,is_open,pretrade_date',
    is_open='0'
)
```

### 分页与字段校验

- 多数接口支持 `limit` / `offset`。部分参考文档中的“单次最大 N 行”是旧版默认值，prd 实测可以通过 `limit` 返回更多行；大批量取数仍建议按 `trade_date`、`ts_code` 或日期区间分批。
- `fields` 会在服务端校验字段名：不存在的字段会直接报错（例如 `接口daily不包含字段xxx`），因此不要把旧版 Tushare 文档里的字段名直接套用到 prd。
- 不要依赖“未知参数会被忽略”来试错；参数名写错时可能静默返回未过滤的数据。
