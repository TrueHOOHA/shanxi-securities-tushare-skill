## 调取数据

下面介绍两种常用的数据调取方式：

1. 通过 `tushare` Python 包
2. 使用 HTTP 协议直接获取

## 前提条件

1. 已经在山西证券开户并开通 PTrade 业务。
2. 已经获取到山西证券 Tushare 的 token 码。

---

## Python SDK

### 1. 导入库

导入山西证券专用的 tushare 库（下载地址咨询山西证券客服热线：95573）。

```python
import sxsc_tushare as sx
```

### 2. 设置 Token

```python
sx.set_token("**********************************")
```

> **注意**：以上方法只需要在第一次或者 token 失效后调用，完成调取 tushare 数据凭证的设置，正常情况下不需要重复设置。

### 3. 初始化 Pro 接口

```python
pro = sx.get_api(env="***")
```

**环境参数说明：**

- **生产环境**：`pro = sx.get_api(env="qa")` *(注：原文如此，通常生产环境为 prd，请根据实际文档确认)*
- **仿真环境**：`pro = sx.get_api(env="prd")`
- **纯 Python 环境**：`pro = sx.get_api(env="prd")`

### 4. 数据调取

以获取交易日历信息为例：

**方式一：直接调用方法**

```python
df = pro.trade_cal(
    exchange='', 
    start_date='20180901', 
    end_date='20181001', 
    fields='exchange,cal_date,is_open,pretrade_date', 
    is_open='0'
)
```

**方式二：使用 query 通用方法**

```python
df = pro.query(
    'trade_cal', 
    exchange='', 
    start_date='20180901', 
    end_date='20181001', 
    fields='exchange,cal_date,is_open,pretrade_date', 
    is_open='0'
)
```

## HTTP 协议方式

HTTP RESTful 采用 `POST` 方式，通过 JSON Body 传入接口参数。

- **请求地址**：`http://221.204.19.233:7172

### 输入参数

| 参数名 | 说明 |
| :--- | :--- |
| `api_name` | 接口名称 |
| `token` | 用于识别唯一用户的标识 |
| `params` | 接口参数，如 daily 接口中 `start_date` 和 `end_date` |
| `fields` | 字段列表，用于接口获取指定的字段，以逗号分隔，如 `"open,high,low,close"` |

### 输出参数

| 参数名 | 说明 |
| :--- | :--- |
| `code` | 接口返回码，`2002` 表示权限问题 |
| `msg` | 错误信息 |
| `data` | 具体数据。成功的请求包含 `fields` 和 `items` 字段，两者数据一一对齐 |

### 请求示例

采用命令行工具 `curl` 的请求示例如下：

```bash
curl -X POST -d '{
    "api_name": "trade_cal", 
    "token": "xxxxxxxx", 
    "params": {
        "exchange":"", 
        "start_date":"20180901", 
        "end_date":"20181001", 
        "is_open":"0"
    }, 
    "fields": "exchange,cal_date,is_open,pretrade_date"
}' http://221.204.19.233:7172
```

### 返回结果示例

```json
{
    "code": 0,
    "msg": null,
    "data": {
        "fields": [
            "exchange",
            "cal_date",
            "is_open",
            "pretrade_date"
        ],
        "items": [
            ["SSE", "20180901", 0, "20180831"],
            ["SSE", "20180902", 0, "20180831"],
            ["SSE", "20180908", 0, "20180907"],
            "...",
            ["SSE", "20180929", 0, "20180928"],
            ["SSE", "20180930", 0, "20180928"],
            ["SSE", "20181001", 0, "20180928"]
        ]
    }
}
```
