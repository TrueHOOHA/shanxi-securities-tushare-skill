## 个股异常波动

* * *

**接口：stk_shock**  

根据证券交易所交易规则的有关规定，交易所每日发布股票交易异常波动情况。

## 概述

根据证券交易所交易规则的有关规定，交易所每日发布股票交易异常波动情况。

- **接口方法**：`pro.stk_shock()`
- **限量**：单次最大1000条，可根据代码或日期循环提取
- **适用场景**：监控股票异常交易、风险预警、量化因子构建

---

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| ts_code | str | N | 股票代码（可通过 `stock_basic` 获取，如 `000001.SZ`） |
| trade_date | str | N | 交易日期（YYYYMMDD 格式，如 `20260312`） |
| start_date | str | N | 开始日期（YYYYMMDD 格式） |
| end_date | str | N | 结束日期（YYYYMMDD 格式） |

**参数说明**：
- `ts_code`、`start_date`/`end_date`、`trade_date` 至少三选一
- 建议使用日期范围（`start_date` + `end_date`）进行批量提取
- 单次调用返回最多1000条记录，超出需分页

---

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|----------|------|
| ts_code | str | Y | 股票代码 |
| trade_date | str | Y | 公告日期 |
| name | str | Y | 股票名称 |
| trade_market | str | Y | 交易所（沪市主板/深市主板/创业板/科创板等） |
| reason | str | Y | 异常波动说明 |
| period | str | Y | 异常期间（起始-结束日期） |

## 代码示例

### 基本用法

```python
import sxsc_tushare as sx

# 1. 初始化
sx.set_token("your_token")
pro = sx.get_api(env="prd")

# 2. 获取某日的所有个股异常波动信息
df = pro.stk_shock(trade_date='20260312')
print(f"共 {len(df)} 条异常记录")
print(df[['ts_code', 'name', 'reason', 'period']].head())

# 3. 获取特定股票的历史异常波动
df = pro.stk_shock(
    ts_code='002015.SZ',
    start_date='20250101',
    end_date='20251231'
)
print(f"协鑫能科异常波动次数：{len(df)}")
```

### 批量获取（分页处理）

```python
import time
import pandas as pd
import sxsc_tushare as sx

sx.set_token("your_token")
pro = sx.get_api(env="prd")

def fetch_all_shock(start_date, end_date):
    """获取指定日期范围内的所有异常波动记录"""
    # 先获取交易日历
    cal = pro.trade_cal(exchange='SSE', start_date=start_date, end_date=end_date, is_open='1')
    trading_dates = cal['cal_date'].tolist()
    
    all_data = []
    for trade_date in trading_dates:
        try:
            df = pro.stk_shock(trade_date=trade_date)
            if not df.empty:
                all_data.append(df)
            time.sleep(0.1)  # 避免频率限制
        except Exception as e:
            print(f"日期 {trade_date} 失败: {e}")
    
    return pd.concat(all_data, ignore_index=True) if all_data else pd.DataFrame()

# 执行批量获取
result = fetch_all_shock('20250101',20251231')
result.to_csv('stock_shock_2025.csv', index=False, encoding='utf-8-sig')
```

### 异常筛选与分析

```python
# 筛选连续涨幅偏离的股票
df = pro.stk_shock(start_date='20250101', end_date='20251231')
# 查找含有"连续三个交易日"的异常
mask = df['reason'].str.contains('连续三个交易日')
frequent_shocks = df[mask]
print("频繁异常波动股票：")
print(frequent_shocks['name'].value_counts().head(10))
```

## 常见问题

### Q1：为什么有些日期返回空？

**A**：不是每个交易日都有异常波动记录。如果市场平稳，该接口可能返回空 DataFrame。

### Q2：如何处理频率限制？

**A**：接口限制约200次/分钟。批量获取时：

```python
import time
for date in dates:
    df = pro.stk_shock(trade_date=date)
    time.sleep(0.1)  # 100ms 延迟
```

### Q3：异常类型有哪些？

**A**：常见 `reason` 值：
- `连续三个交易日涨跌幅偏离值累计达到12%的ST证券,*ST证券` - ST类股票
- `连续三个交易日内涨跌幅偏离值累计达20%` - 主板/中小板
- `连续3个交易日内收盘价格涨跌幅偏离值累计达30%` - 科创板/创业板
- `连续10个交易日内收盘价格涨幅偏离值累计达100%` - 严重异常波动
