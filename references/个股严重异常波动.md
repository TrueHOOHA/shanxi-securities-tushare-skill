## 个股严重异常波动

* * *

**接口：stk_high_shock**  

根据证券交易所交易规则的有关规定，交易所每日发布股票交易严重异常波动情况。

## 概述

根据证券交易所交易规则的有关规定，交易所每日发布股票交易严重异常波动情况。

- **接口方法**：`pro.stk_high_shock()`
- **限量**：单次最大1000条，可根据代码或日期循环提取
- **适用场景**：监控高风险股票、极端行情预警、退市风险识别

---

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| ts_code | str | N | 股票代码（可通过 `stock_basic` 获取，如 `000001.SZ`） |
| trade_date | str | N | 交易日期（YYYYMMDD 格式，如 `20260312`） |
| start_date | str | N | 开始日期（YYYYMMDD 格式） |
| end_date | str | N | 结束日期（YYYYMMDD 格式） |

**参数说明**：
- 参数可选，但建议至少指定一个维度（代码或日期）以控制返回量
- 无参数调用返回当日全部严重异常波动记录
- 支持分页循环提取

---

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|----------|------|
| ts_code | str | Y | 股票代码 |
| trade_date | str | Y | 公告日期 |
| name | str | Y | 股票名称 |
| trade_market | str | Y | 交易所（沪市主板/深市主板/创业板/科创板等） |
| reason | str | Y | 严重异常说明 |
| period | str | Y | 异常期间（起始-结束日期） |

## 代码示例

### 基本用法

```python
import sxsc_tushare as sx

# 1. 初始化
sx.set_token("your_token")
pro = sx.get_api(env="prd")

# 2. 获取某日的所有个股严重异常波动信息
df = pro.stk_high_shock(trade_date='20260312')
print(f"共 {len(df)} 条严重异常记录")
print(df[['ts_code', 'name', 'reason', 'period']])

# 3. 获取特定股票的历史严重异常波动
df = pro.stk_high_shock(
    ts_code='002015.SZ',
    start_date='20250101',
    end_date='20251231'
)
print(f"协鑫能科严重异常波动次数：{len(df)}")
```

### 风险监控脚本

```python
import pandas as pd
import sxsc_tushare as sx
from datetime import datetime, timedelta

sx.set_token("your_token")
pro = sx.get_api(env="prd")

def monitor_high_shock(days=30):
    """监控最近N天的严重异常波动股票"""
    end = datetime.now().strftime('%Y%m%d')
    start = (datetime.now() - timedelta(days=days)).strftime('%Y%m%d')
    
    df = pro.stk_high_shock(start_date=start, end_date=end)
    
    if df.empty:
        print("最近{days}天无严重异常波动记录")
        return
    
    # 统计发生次数
    counts = df['name'].value_counts()
    print("=== 严重异常波动预警 ===")
    print(f"监测期间：{start} ~ {end}")
    print(f"涉及股票数：{df['ts_code'].nunique()} 只")
    print("\n高频异常股票（>1次）：")
    print(counts[counts > 1])
    
    return df

# 执行监控
risk_stocks = monitor_high_shock(days=30)
```

### 按异常类型分类

```python
# 获取最近一年的所有严重异常波动
df = pro.stk_high_shock(start_date='20250101', end_date='20251231')

# 分类统计
categories = {
    '10日累计100%': df[df['reason'].str.contains('10个交易日内.*100%')],
    '30日累计200%': df[df['reason'].str.contains('30个交易日内.*200%')],
    '多次同向波动': df[df['reason'].str.contains('次出现')],
}

for cat, data in categories.items():
    print(f"{cat}: {len(data)} 次")
```

## 异常波动等级说明

| 波动等级 | 阈值 | 说明 |
|---------|------|------|
| 一般异常波动 | 连续3日累计偏离值达20%（主板）/30%（科创板/创业板） | `stk_shock` 接口覆盖 |
| 严重异常波动 | 连续10日累计涨幅达100% 或 30日累计200% | `stk_high_shock` 接口覆盖 |
| 多次同向波动 | 10个交易日内出现4次以上同向异常波动 | `stk_high_shock` 接口覆盖 |

## 常见问题

### Q1：`stk_shock` 和 `stk_high_shock` 的区别？

**A**：
- `stk_shock`：一般异常波动（3个交易日）
- `stk_high_shock`：严重异常波动（10日/30日累计）

两者数据独立，建议同时监控。

### Q2：如何识别退市风险股票？

**A**：`stk_high_shock` 中的 `*ST` 股票出现多次严重异常波动时，需警惕退市风险：

```python
df = pro.stk_high_shock(start_date='20250101', end_date='20251231')
st_stocks = df[df['name'].str.contains('\*ST|ST')]
print("ST类严重异常波动股票：")
print(st_stocks[['ts_code', 'name', 'reason']])
```

### Q3：是否可以获取历史全部数据？

**A**：可以，但需分页循环：

```python
# 按年份批量获取
import pandas as pd
all_data = []
for year in range(2015, 2026):
    df = pro.stk_high_shock(start_date=f'{year}0101', end_date=f'{year}1231')
    all_data.append(df)
full_history = pd.concat(all_data, ignore_index=True)
```

## 关联接口

| 接口名称 | 方法 | 说明 |
|---------|------|------|
| 个股异常波动 | `stk_shock` | 3个交易日的常规异常波动 |
| 交易所重点提示证券 | `stk_alert` | 交易所发布的重点提示（含风险提示期） |
| 股票基础信息 | `stock_basic` | 获取股票代码、名称、退市状态等 |

---

## 风险提示

- 严重异常波动股票可能面临停牌、ST处理、退市等风险
- `period` 字段显示风险提示期间，注意截止日期
- 建议结合 `stock_basic` 的 `list_status` 字段判断股票状态
