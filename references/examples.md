## 单票行情

- 看下宁德时代最近三个月走势
- 茅台今年以来涨了多少
- 招行这两年最大回撤大概多少

**执行要点：**
1. 解析标的 → `ts_code` 标准格式（如 `300750.SZ`）
2. 确定时间范围（"三个月" → 约 60 交易日）
3. 查 `API接口对应表.md` → `daily`（日线）、`daily_basic`（指标）
4. 输出：一句结论 + 关键数字（涨跌幅、最高/最低、波动率）

## 财务 / 估值

- 看下比亚迪最近 8 个季度营收和净利润趋势
- 茅台现在估值算高吗
- 帮我找高 ROE 低负债的公司

**执行要点：**
1. 查 `API接口对应表.md` → `income`（营收/净利润）、`fina_indicator`（ROE/毛利率）
2. 时间范围："8 个季度" → 最近 2 年季度数据
3. 估值对比：联动 `daily_basic`（PE/PB/股息率）
4. 筛选场景：结合 `stock_basic`（行业分类）+ 财务指标排序

## 对比

- 比一下茅台、五粮液、泸州老窖近一年的涨幅和估值
- 对比一下沪深300、中证500、创业板今年表现

**执行要点：**
1. 统一时间口径（"近一年" → 252 交易日）
2. 统一对比指标（涨跌幅、PE、ROE、营收增速）
3. 查 `API接口对应表.md` → `index_daily`（指数行情）
4. 输出对比表 + "谁更强"总结

## 资金流 / 板块

- 今天北向资金流入最多的股票有哪些
- 最近哪个板块最强
- 半导体板块最近一个月强不强

**执行要点：**
1. 查 `API接口对应表.md` → `moneyflow_hsgt`（沪深港通）
2. 板块强度：查 `API接口对应表.md` → `index_daily`（申万行业指数）
3. 时间窗："今天" → 当前交易日，"一个月" → 20 交易日
4. 联动价格表现，避免把单日噪声说成趋势

## 公告 / 事件

- 帮我梳理下寒武纪最近的重要公告
- 最近机器人板块有什么消息面催化

**执行要点：**
1. 查 `API接口对应表.md` → `anns_d`（公告）
2. 时间窗："最近" → 默认 30 天
3. 去噪，提炼 3～5 条主线
4. 区分事实公告、媒体解读、研报观点

## 宏观

- 看一下最近 CPI、PPI、PMI 变化
- 当前市场风格偏成长还是价值

**执行要点：**
1. 查 `API接口对应表.md` → `cn_cpi`、`cn_ppi`、`cn_pmi`
2. 时间范围："最近" → 最近 6～12 期
3. 市场风格：结合 `index_daily`（风格指数对比）

## 导出

- 把沪深300成分股近两年日线导成 CSV
- 下载宁德时代 2020 到现在的复权行情
- 把最近 3 年 ROE、PE、PB、营收增速拉成一个表

**执行要点：**
1. 查 `API接口对应表.md` → `stock_basic`（成分股列表）
2. 分段拉取（按年切片），避免超时
3. 输出格式：CSV / parquet + 元信息文件
4. 命名规范：`daily_600519.SH_20230101_20231231_20260322.csv`
