## 交易所重点提示证券

* * *

**接口：stk_alert**  

根据证券交易所交易规则的有关规定，交易所每日发布重点提示证券。

## 概述

根据证券交易所交易规则的有关规定，交易所每日发布重点提示证券。

- **接口方法**：`pro.stk_alert()`
- **限量**：单次最大1000条，可根据代码或日期循环提取
- **适用场景**：获取交易所官方风险提示、关注重点监控证券

---

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| ts_code | str | N | 股票代码（可通过 `stock_basic` 获取，如 `000001.SZ`） |
| trade_date | str | N | 交易所重点提示起始日期（YYYYMMDD 格式，如 `20260312`） |
| start_date | str | N | 开始日期（YYYYMMDD 格式） |
| end_date | str | N | 结束日期（YYYYMMDD 格式） |

**参数说明**：
- `trade_date` 指重点提示的**起始日期**，不是公告日期
- `start_date`/`end_date` 用于范围筛选
- 返回记录包含 `start_date` 和 `end_date` 两个字段，表示提示期间

---

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|----------|------|
| ts_code | str | Y | 股票代码 |
| name | str | Y | 股票名称 |
| start_date | str | Y | 交易所重点提示起始日期 |
| end_date | str | Y | 交易所重点提示参考截至日期 |
| type | str | Y | 提示类型（如"交易所重点提示证券"） |

## 代码示例

### 基本用法

```python
import sxsc_tushare as sx

# 1. 初始化
sx.set_token("your_token")
pro = sx.get_api(env="prd")

# 2. 获取某日所有重点提示证券
df = pro.stk_alert(trade_date='20260311')
print(f"共 {len(df)} 只重点提示证券")
print(df[['ts_code', 'name', 'start_date', 'end_date']])

# 3. 获取特定股票的历史重点提示
df = pro.stk_alert(ts_code='001896.SZ', start_date='20250101', end_date='20251231')
print(f"豫能控股重点提示次数：{len(df)}")
for _, row in df.iterrows():
    print(f"  {row['start_date']} ~ {row['end_date']}")
```

### 批量监控脚本

```python
import pandas as pd
import sxsc_tushare as sx
from datetime import datetime, timedelta

sx.set_token("your_token")
pro = sx.get_api(env="prd")

def get_recent_alerts(days=7):
    """获取最近N天起始的重点提示证券"""
    today = datetime.now()
    start = today - timedelta(days=days)
    
    all_alerts = []
    cur = start
    while cur <= today:
        trade_date = cur.strftime('%Y%m%d')
        try:
            df = pro.stk_alert(trade_date=trade_date)
            if not df.empty:
                all_alerts.append(df)
        except:
            pass
        cur += timedelta(days=1)
    
    if all_alerts:
        result = pd.concat(all_alerts, ignore_index=True)
        return result.drop_duplicates(subset=['ts_code', 'start_date'])
    return pd.DataFrame()

# 执行监控
alerts = get_recent_alerts(days=7)
if not alerts.empty:
    print(f"最近7天重点提示证券：{len(alerts)} 条记录")
    print(alerts[['ts_code', 'name', 'start_date', 'end_date']].to_string())
else:
    print("无重点提示证券")
```

### 识别高风险股票

```python
# 获取最近一个月所有重点提示
df = pro.stk_alert(start_date='20250301', end_date='20250331')

# 筛选被多次提示的股票
frequent = df.groupby('ts_code').agg({
    'name': 'first',
    'start_date': 'count'
}).rename(columns={'start_date': '提示次数'}).sort_values('提示次数', ascending=False)

print("频繁被重点提示的股票：")
print(frequent.head(10))
```

## 使用建议

### 1. 结合严重异常波动数据

`stk_alert` 和 `stk_high_shock` 通常有关联。同时查询可获取更完整风险画面：

```python
# 获取某股票的所有风险提示
code = '001896.SZ'
start, end = '20250101', '20251231'

alerts = pro.stk_alert(ts_code=code, start_date=start, end_date=end)
high_shocks = pro.stk_high_shock(ts_code=code, start_date=start, end_date=end)

print(f"重点提示：{len(alerts)} 次")
print(f"严重异常波动：{len(high_shocks)} 次")
```

### 2. 关注提示期间

`end_date` 是"参考截至日期"，不代表风险结束。建议：
- 在 `end_date` 后继续监控
- 查看是否产生新的提示记录

### 3. 筛选ST股票

重点提示证券中 ST、*ST 股票占比高，需特别关注退市风险：

```python
alerts = pro.stk_alert(start_date='20250101', end_date='20251231')
st_alerts = alerts[alerts['name'].str.contains('ST')]
print(f"ST类重点提示：{len(st_alerts)} 条")
```

## 常见问题

### Q1：`trade_date` 和 `start_date` 的区别？

**A**：
- `trade_date`：指重点提示的**起始日期**（筛选条件）
- 返回的 `start_date`：该条提示的起始日期
- 返回的 `end_date`：该条提示的参考截至日期

### Q2：提示类型有哪些？

**A**：当前仅见 `type="交易所重点提示证券"`，未来可能增加其他类型（如"交易监控证券"、"风险警示证券"等），建议将 `type` 字段纳入筛选条件。

### Q3：如何获取连续多日的提示？

**A**：使用日期范围循环：

```python
def get_alerts_range(start_date, end_date):
    dates = pd.date_range(start=start_date, end=end_date, freq='B')  # 仅交易日
    results = []
    for d in dates:
        try:
            df = pro.stk_alert(trade_date=d.strftime('%Y%m%d'))
            results.append(df)
        except:
            pass
    return pd.concat(results, ignore_index=True) if results else pd.DataFrame()
```

## 注意事项

1. **提示不等于处罚**：重点提示是交易所的关注信号，不代表已违规
2. **持续监控**：某只股票可能被连续多日提示
3. **结合其他数据**：建议结合 `stk_shock`、`stk_high_shock`、财务数据等综合判断
4. **ST风险**：频繁被提示的 ST 股票面临退市风险，需谨慎
